কাজের বন্ধু — Native Android প্রাথমিক প্রকল্প (v1.0)
Kotlin Android অ্যাপের হোম স্ক্রিন, বিভাগ, মেনু ও নীচের নেভিগেশন অন্তর্ভুক্ত।
এটি UI ডেমো: অনলাইন পোস্ট, লগইন, চ্যাট, GPS, বুকিং ও অ্যাডমিন ব্যাকএন্ড এখনো নেই।
GitHub Actions workflow দিয়ে বিনামূল্যের quota-র মধ্যে debug APK build করার চেষ্টা করা যাবে।
